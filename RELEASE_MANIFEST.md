# Release manifest

This file connects every table and number of the paper (`paper_make.tex`, generated by `build_paper.py` from `paper_src/`) to the code that
produced it, the exact command and settings, and the saved results. Reference
implementations are pinned to commits. First release: `ed192721a9a38432fe39083b37f6da46a786bb4e` (tag `paper-final`,
10 October). The files of this tree include the revisions listed under "Changes after the first release" below;
the tag `paper-final` must point to the commit that contains them, and `release_record.json` lists the SHA-256 of
every file of that version (`python3 make_release_record.py`, checked by `python3 verify_paper_tables.py`).

Environment of the reported runs: Python 3.12, PyTorch 2.6.0, NumPy 1.26.4,
SciPy 1.14.1, transformers 4.45.1; Apple Silicon, MPS, float32 throughout.

Both tests download the pinned file at run time (cached in
`tests/.official_cache/`, git-ignored; the FSD repository has no license) and
print `OK ...` on success; they print `SKIP` if the file cannot be fetched.

Relation to the published methods (details in Appendix D of the paper):

* **FSD-style (adapted).** Scoring (`p_theta - alpha * p_omega`, top-k = 6) and
  the recursive residual-mass anti-LM equal the official code (checked to
  1e-9). Deviations: it samples from the top-k scores instead of the official
  argmax, and `p_theta` is the temperature-scaled softmax.
* **LZ Penalty (adapted).** The penalty vector equals the reference
  `compute_lz_penalty_stateless` exactly (max difference 0.0). The history it is
  given differs: prompt and generated tokens, last `buffer_size + window_size`
  of them, instead of generated tokens only in a window of `lz_lookback_size`.

## Merge provenance of the FSD/LZ rows

The FSD-style and LZ Penalty rows of the main, non-fiction, GPT-2, OLMo and
Mistral tables were regenerated after their decoders changed, with `--only`
reruns merged into the earlier complete runs (the earlier run directories are
never modified):

1. `*_v2_merged` / `main_comparison_v6_fsdlz_merged`: LZ Penalty ported from the
   reference; FSD-style with fixed interpolation weights (superseded).
2. `*_v3_merged` / `main_comparison_v7_fsd2_merged`: FSD-style with the official
   recursive residual-mass anti-LM (final).

The pilot human evaluation used the FSD-style version of step 1 (see
`verify_human_eval_passages.py`).

## Changes after the first release (`ed19272`)

* **Solver for the one-step problem** (`one_step_projection.py`, used by `budget_ladder.py` and
  `synthetic_fsm_hazard.py`): the multiplier bracket now expands until the budget is met (previously a
  fixed upper limit of 200 / 1000 could stop the search early), the final distribution is checked, and a
  failed solve raises `SolverFailure`. Re-run results: `synthetic_fsm_results.json` and
  `functional_form_ablation.json` changed by at most 1e-10; in `budget_ladder.json` the always-feasible
  budget at strong control in the persistent systems changed by up to 23 % (it had stopped early), and the
  other rules by less than 1e-6 (ratios).
* **Rule for a budget that cannot be met**: sample from `p` restricted to the minimum-risk actions
  (tolerance 1e-12 in the exact code, 1e-6 in the float32 decoder). `src/decoding.py` previously used a
  finite penalty `lambda = 1e4`; the exact code used `lambda = 200`. Every reported language-model run has
  a dual feasible rate of 1.0 and a structurally-infeasible rate of 0.0 (checked by
  `verify_paper_tables.py`), so the branch was not executed in any reported run and no language-model
  result changed. `tests/test_infeasible_rule.py` checks that the decoder and the exact solver agree.
* **Statements corrected in the paper**: the fixed-budget cost ratio tends to the finite limit
  `1/phi_max = 707.08` as the reduction goes to zero (it does not grow without bound); `1/phi` is a bound
  on the second-order cost only; absolute KL is reported next to ratios.
